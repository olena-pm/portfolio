# Olena Lobachova Portfolio Website

Professional profile website for Olena Lobachova, Senior Product Manager.

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- GitHub Pages

## Structure

- `index.html` — main page
- `css/style.css` — styles
- `js/main.js` — interactions
- `assets/` — images, favicon, CV files

## Deployment

This website is designed to be deployed via GitHub Pages.
